# Lokalizacja interfejsu

`src/shared/i18n` we frontendzie zawiera provider języka, hook `useTranslation`,
przełącznik i słownik angielski. Polski jest językiem domyślnym. Preferencja
`broken-ranks-tool.language.v1` jest oddzielona od draftów, biblioteki i plików
buildów. Zablokowany localStorage nie blokuje przełącznika. Zdarzenie `storage`
synchronizuje wybór między kartami; nieobsługiwana wartość oznacza polski.

W nagłówku obok PL/EN znajduje się wybór „Nazwy modów”. Jest wspólną preferencją
interfejsu, synchronizowaną ze stanem otwartego optymalizatora bez ponawiania
obliczeń, zmiany priorytetów ani pozostałych ustawień. Wersja mobilna grupuje
oba wybory w drugim wierszu nagłówka.

Każdy tekst interfejsu, tooltip, placeholder i etykieta dostępności przechodzi
przez `t` z `useTranslation`. Wiadomość źródłowa po polsku jest kluczem w
`en.json`, zgodnie z podejściem gettext. Przykład:

```jsx
const { t } = useTranslation();
<button aria-label={t("Dodaj punkt: {0}", [t(statLabel)])}>
    {t("Dodaj punkt")}
</button>;
```

Przy nowym tekście dodaj równocześnie wersję angielską. Parametry `{0}`, `{1}`
muszą występować w obu wersjach. Nie sklejaj tłumaczeń fragmentów zdania, jeśli
można przekazać pełną wiadomość z parametrami. Teksty wygenerowane przez czyste
funkcje prezentacji otrzymują translator jako argument; memoizacja zależy od
`t` lub `locale`, gdy wynik zależy od języka.

Nazwy własne przedmiotów i kamieni oraz nazwy buildów podane przez gracza
pozostają dosłowne. Tłumaczone są opisy bonusów, slotów, profesji i działań.
Nie tłumacz identyfikatorów enumów, kluczy statystyk w API, wartości formularzy
ani zawartości zapisanych buildów. Etykietę statystyki `Siła` można pokazać jako
`Strength`, ale aktualizacja przydziału nadal używa klucza `Siła`.

Istniejące komunikaty walidacji i raporty API są tłumaczone przy wyświetlaniu.
Dzięki temu już otrzymany wynik i zapisany komunikat reagują na zmianę języka,
bez ponawiania obliczeń. Wzorce pełnych komunikatów w słowniku rozpoznają ich
parametry. `messageParameters.js` wskazuje wyłącznie te parametry, które są
etykietą lub zagnieżdżonym komunikatem i wymagają dalszego tłumaczenia. Pozostałe
parametry, zwłaszcza nazwy własne i nazwy plików, są zachowywane.

Hook udostępnia `locale` (`pl-PL` / `en-GB`) do formatowania i sortowania.
Provider aktualizuje `html[lang]` i opisy metadanych. Tłumaczenia są renderowane
przez React; nie zmieniają DOM po renderowaniu ani nie wstawiają HTML z tekstu.

Testy `src/shared/i18n` sprawdzają parametry słownika, komunikaty, zapis wyboru,
brak dostępu do pamięci oraz zmianę języka bez zmiany danych postaci i raportu.
`e2e/localization.spec.js` obejmuje główne widoki desktop/mobile, wyszukiwanie
bonusów po angielsku, odświeżenie strony i zachowanie przydziału punktów.
